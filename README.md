Foto degli allestimenti usate per sito e social. `archivio.json` elenca ogni foto con tema, descrizione,
marchio (spettacolando / raffaella) e dove è già stata usata. URL pubblico di ogni foto:
https://raw.githubusercontent.com/spettacolando-digitale/spettacolando-siti/archivio-foto/<file>
